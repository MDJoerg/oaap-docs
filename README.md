# OAAP Anwender-Dokumentation

Die Dokumentation der **Open Application & Automation Platform** für
Betreiber und Anwender — auf Deutsch, Schritt für Schritt, ohne
vorausgesetztes Spezialwissen.

> Stand: Referenz **0.1.42** (2026-08-23). Jede Seite nennt oben die
> Version, gegen die sie geprüft wurde.

## Aufbau

| Ordner | Inhalt |
| ------ | ------ |
| [szenarien/](szenarien/README.md) | Schritt-für-Schritt-Anleitungen je Situation: Server aufsetzen, App installieren, App-Projekt mit KI, Produktivsetzung, … |
| [apps/](apps/README.md) | Dokumentation der OAAP-eigenen Apps (Studio, FleetView, Store Editor, …) und der kuratierten Pakete |
| [betrieb/](betrieb/architektur-kurz.md) | Für Betreiber und Prüfer: wie ein Knoten von innen aussieht — Ports, Netze, Datenfluss, Dateisystem, Geheimnisse, Backup, bekannte Grenzen |
| [cli/](cli/README.md) | Referenz aller `oaap`-Befehle mit Beispielen |

## Wo diese Doku verfügbar ist

Eine Quelle (dieses Repository), drei Auslieferungen:

1. **Hilfecenter-App** aus dem OAAP-Store — die Doku läuft dann als App
   auf dem eigenen Knoten, offline und hinter der Firewall (geplant).
2. **Öffentliche Site** über GitHub Pages (geplant).
3. **Portal-Verweis** — eine Launchpad-Kachel zeigt auf die
   Hilfecenter-Instanz.

## Mitmachen / Fehler melden

Fehler in der Doku sind Fehler: gern als Issue in diesem Repository —
oder direkt der Plattform-KI sagen, die pflegt hier mit.
